Wrestling - Website Plan

1 Site Name

Site Name: Wrestling

why: I picked this name because the site will teach new people the basics of wrestling. It will cover history, match types and famous wrestlers.

2 Site Purpose

This website will help new fans to learn about wrestling. It will explain the history of wrestling, it will show different types of matches, it will talk about famous wrestlers and their moves. So my aim is to show how wrestling mixes sports and entertainment

3 Scenarios

  • What are the types of wrestling matches?
  • Who are the most famous wrestlers and what are they finishing moves?

4 Color Schema

Primary Color: #C41E3A - Red - Used for headings.

Secondary Color: #333 - Black - Used for background

Accent Color: #CCC - White - Used for text backgrounds

5 Typography

Heading Font:Arial,sans-serif - Bold font for titles.

Body Font: Roboto - for all text.

6 Wireframes

Mobile View

One column layout. Header, navigation menu, main content, and footer are stacked vertically.

Desktop View

Two column layout. Header with horizontal navigation at the top. Main content on left, sidebar on right. Footer with 3 parts at bottom.
